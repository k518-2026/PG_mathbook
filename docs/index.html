📚 プロジェクトの理念と重複管理について

本ライブラリは、18〜19世紀の偉大な数学者たち（ラプラス、ジョン・ヴェン、ジョージ・ブール）が著したパブリックドメインの原典を底本とし、現代の高校生が「論理・確率・統計」の本質を直感と数式の両面から深く学べるよう、教育情報分析研究会が編纂・組版したものです。

書籍の追加・更新は catalog.json を通じて厳格に重複判定され、同一 Gutenberg ID の二重登録を防止しています。また、すべての原著名には原著（Project Gutenberg EBook）への直リンクを配備し、いつでも一次資料へと立ち返ることができるオープンな数学教育環境を提供しています。
