\chapter{解析的非ユークリッド幾何学}

我々は通常の極座標 $(\rho, \theta)$ および直交座標系 $(x, y)$ を用いて、非ユークリッド幾何学の諸性質を解析的に定式化する。

\section{双曲解析幾何学}

\begin{figure}[htbp]
\centering
\includegraphics[width=60mm]{fig61.png}
\caption{双曲平面における極座標と直交座標の幾何学的関係}
\end{figure}

\begin{enumerate}[label=\textbf{\arabic*.}]
\item \textbf{極座標と直交座標の関係}：
原点から点 $(\rho, \theta)$ への動径が各軸となす角と直角三角形の関係から、純虚数引数を用いた以下の美しい関係式が得られる：
\[
\tan ix = \cos\theta \tan i\rho, \quad \tan iy = \sin\theta \tan i\rho
\]
すなわち、実関数表示では、
\[
\tanh x = \cos\theta \tanh \rho, \quad \tanh y = \sin\theta \tanh \rho
\]
および、
\[
\cosh \rho = \cosh x \cosh y
\]

\item \textbf{2点間の距離 $\delta$}：
2点 $(\rho, \theta)$ と $(\rho', \theta')$ の間の距離 $\delta$ は、双曲余弦定理より以下で与えられる：
\[
\cosh \delta = \cosh \rho \cosh \rho' - \sinh \rho \sinh \rho' \cos(\theta - \theta')
\]
これを直交座標系 $(x, y)$ および $(x', y')$ で表すと、
\[
\cosh \delta = \cosh x \cosh x' \cosh(y - y') - \sinh x \sinh x'
\]

\item \textbf{直線の解析方程式}：
原点から直線に下ろした垂線の長さを $p$、その垂線が $x$ 軸となす角を $\alpha$ とするとき、直線の方程式は以下となる：
\[
\tan i p = \tan i \rho \cos(\theta - \alpha) = \cos\alpha \tan ix + \sin\alpha \tan iy
\]
したがって、双曲平面における任意の直線の一般方程式は、ワイエルシュトラス的同次形式として次のように表される：
\[
A \tanh x + B \tanh y + C = 0
\]

\item \textbf{点と直線との距離 $\delta$}：
点 $(x_1, y_1)$ から直線 $A \tanh x + B \tanh y + C = 0$ への距離 $\delta$ は、
\[
\sinh \delta = \frac{|A \tanh x_1 + B \tanh y_1 + C|}{\sqrt{A^2 + B^2 - C^2}}
\]

\item \textbf{円の方程式}：
中心 $(x_0, y_0)$、半径 $r$ の円の方程式は、
\[
\cosh x \cosh x_0 \cosh(y - y_0) - \sinh x \sinh x_0 = \cosh r
\]

\item \textbf{限界線（ホロサイクル）の方程式}：
原点を通り $x$ 軸の負の方向を軸とする限界線の方程式は、
\[
e^{-x} = \cosh y
\]

\item \textbf{等距離曲線の方程式}：
$x$ 軸からの距離が $c$ である等距離曲線の方程式は、
\[
y = \pm c
\]
であり、曲率一定の軌跡を与える。

\item \textbf{微小線素と面積要素}：
双曲平面におけるリーマン計量（線素 $ds$）および面積要素 $dS$ は、極座標および直交座標において以下のように与えられる：
\[
ds^2 = d\rho^2 + \sinh^2 \rho\, d\theta^2 = \cosh^2 y\, dx^2 + dy^2
\]
\[
dS = \sinh \rho\, d\rho\, d\theta = \cosh y\, dx\, dy
\]
\end{enumerate}

\section{楕円解析幾何学}

楕円平面においては、直線の全長が有限（$\pi$）であり、曲率は正の定数（$+1$）となる。双曲幾何学における公式の純虚数 $ix, iy$ を通常の実数角 $x, y$ に戻すことにより、すべての公式が直ちに得られる。

\begin{enumerate}[label=\textbf{\arabic*.}]
\item \textbf{極座標と直交座標の関係}：
\[
\tan x = \cos\theta \tan \rho, \quad \tan y = \sin\theta \tan \rho
\]
\[
\cos \rho = \cos x \cos y
\]

\item \textbf{2点間の距離 $\delta$}：
\[
\cos \delta = \cos \rho \cos \rho' + \sin \rho \sin \rho' \cos(\theta - \theta')
\]
\[
\cos \delta = \cos x \cos x' \cos(y - y') + \sin x \sin x'
\]

\item \textbf{直線の一般方程式}：
\[
A \tan x + B \tan y + C = 0
\]

\item \textbf{線素と面積要素}：
\[
ds^2 = d\rho^2 + \sin^2 \rho\, d\theta^2 = \cos^2 y\, dx^2 + dy^2
\]
\[
dS = \sin \rho\, d\rho\, d\theta = \cos y\, dx\, dy
\]
\end{enumerate}

\section{楕円立体解析幾何学}

3次元楕円空間においては、直交座標 $(x, y, z)$ が相互に直交する3つの平面からの距離として定義され、線素は以下で与えられる：
\[
ds^2 = \cos^2 y \cos^2 z\, dx^2 + \cos^2 z\, dy^2 + dz^2
\]
前章で論じたクリフォードの平行線（二重回転面上に載る至る所等距離な非共面直線）は、この計量空間における測地線流として完全に解析的に表現される。
